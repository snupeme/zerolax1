# 1. MAIN DESIGN PRINCIPLE

TARGET AUDIENCE: Grades 1–5.

A child must understand what to do within 3–5 seconds.

Every game must:
- Have one clear objective.
- Show a visual example.
- Use very large buttons.
- Use simple Uzbek instructions.
- Have no complicated controls.
- Avoid unnecessary menus.
- Avoid confusing animations.
- Give immediate feedback.

Use the same basic interaction pattern across all four games.

The child sees a question, understands the task, and chooses the correct answer.

# 2. NEW GAME ONE — JAVOBNI TOP

Mathematical operation: ADDITION.

Example:

Show:
3 red apples + 2 green apples.

Ask:
"Jami nechta olma?"

Show three large answer buttons:
4 | 5 | 6

The child taps 5.

If correct:
- Show a positive animation.
- Display "Barakalla! To‘g‘ri javob!"
- Continue to the next question.

If incorrect:
- Display "Yana bir bor urinib ko‘r!"
- Visually count the apples.
- Show the correct calculation in a simple way.

Gameplay must be extremely straightforward.

# 3. NEW GAME TWO — NECHTA QOLDI?

Mathematical operation: SUBTRACTION.

Example:

Show 5 balloons.

Animate 2 balloons disappearing.

Ask:
"Nechta shar qoldi?"

Show answer buttons:
2 | 3 | 4

The child selects the answer.

Use simple objects:
- Apples.
- Balloons.
- Stars.
- Flowers.
- Toys.

Never require complicated drag-and-drop controls.

# 4. NEW GAME THREE — NECHTA BO‘LDI?

Mathematical operation: MULTIPLICATION.

Example:

Show 2 baskets.

Each basket contains 3 apples.

Ask:
"Jami nechta olma?"

Show:
3 + 3 = ?

Then provide three answer buttons.

After answering, explain:
"2 ta guruh, har birida 3 tadan. Jami 6 ta."

Use visual grouping to explain multiplication.

Introduce multiplication tables gradually according to grade level.

# 5. NEW GAME FOUR — TENGLIK TAQSIMLA

Mathematical operation: DIVISION.

Example:

Show:
6 candies and 2 baskets.

Ask:
"6 ta konfetni 2 ta savatga teng taqsimlasak, har biriga nechtadan tushadi?"

Visually demonstrate equal distribution.

Show three answer buttons:
2 | 3 | 4

After answering, explain:
"Har bir savatda 3 tadan konfet bor."

Do not require dragging objects. Use automatic visual distribution and simple answer selection.

Introduce division only at an appropriate grade level.

# 6. FIRST-TIME GAME EXPLANATION

Every game must have a very short introduction.

Before the first actual round, show one example question with a clear demonstration.

Example:

"Rasmdagi olmalarni sanang va to‘g‘ri javobni bosing."

Highlight the answer buttons.

Include a large button:
"Tushundim, boshlash!"

After the first successful practice question, start the real game.

Do not show long text instructions.
