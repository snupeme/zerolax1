# ZEROLAX — ADVANCED ADMIN CONTROL CENTER
## Professional Admin Dashboard — Full Implementation Prompt

You are a senior full-stack engineer, UI/UX designer, and software architect.

Your task is to build a powerful, modern, professional administration system for the ZEROLAX educational Telegram Mini App.

This must be a real, fully functional admin platform connected to the existing ZEROLAX backend and database — NOT a static dashboard or visual prototype.

The admin panel should feel like a premium SaaS management platform, with excellent usability, clear information architecture, fast navigation, advanced filtering, responsive design, and complete control over the educational platform.

IMPORTANT:
Before coding, inspect the existing project architecture, authentication, database, APIs, Telegram bot, and current admin functionality. Reuse existing systems and preserve working features. Do not create duplicate tables, APIs, or authentication systems unnecessarily.
