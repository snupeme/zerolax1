# 3. GAME ONE — YULDUZLARNI YIG‘ (ADDITION)

Create a fully interactive addition game.

Game concept:
The screen displays two groups of colorful stars, apples, balloons, or other child-friendly objects.

Example:
3 stars + 4 stars = ?

The child counts the objects and selects or enters the answer.

Gameplay:
1. Show an attractive animated scene.
2. Display two groups of objects.
3. Show the addition expression.
4. Provide answer choices or a number input.
5. The child selects an answer.
6. Immediately show whether the answer is correct.
7. Play a positive animation for a correct answer.
8. Explain the correct calculation after a wrong answer.
9. Continue to the next question.

Add:
- Counting animation.
- Objects moving together.
- Number animations.
- Positive sound effects with a mute option.
- Progress indicator.
- Score display.

# 4. GAME TWO — YO‘QOLGANLARNI TOP (SUBTRACTION)

Create an interactive subtraction game.

Game concept:
Display a group of objects.

Example:
There are 10 balloons.
4 balloons fly away.
How many balloons remain?

Gameplay:
1. Display the original objects.
2. Animate the objects being removed.
3. Show the subtraction expression.
4. Ask the child to find the remaining quantity.
5. Allow answer selection or number input.
6. Display immediate feedback.
7. Explain the answer visually.

Use different objects:
- Balloons.
- Apples.
- Stars.
- Toys.
- Flowers.

Difficulty must adapt to the selected grade.

# 5. GAME THREE — GURUHLARNI TO‘LDIR (MULTIPLICATION)

Create an interactive multiplication game.

Game concept:
Show several groups containing equal numbers of objects.

Example:
3 groups.
4 apples in each group.

Ask:
3 × 4 = ?

Gameplay:
1. Display equal groups visually.
2. Highlight each group.
3. Allow the child to count objects.
4. Show the multiplication expression.
5. Provide answer choices or number input.
6. Animate the groups when the answer is correct.
7. Explain multiplication as repeated addition.

Example explanation:
4 + 4 + 4 = 12
3 × 4 = 12

Include multiplication-table challenges suitable for the selected grade.

# 6. GAME FOUR — ADOLATLI TAQSIMLA (DIVISION)

Create an interactive division game.

Game concept:
A child needs to distribute objects equally between characters, boxes, or groups.

Example:
12 candies.
3 children.

Ask:
How many candies does each child receive?

Gameplay:
1. Display the objects.
2. Display the receiving characters or groups.
3. Allow the child to distribute objects using drag-and-drop when supported.
4. Alternatively, provide a simple tap-to-distribute interaction.
5. Show the final division expression.
6. Check whether distribution is equal.
7. Display a positive animation and explanation.

Important:
- For grades 1–2, use simple visual grouping only when suitable.
- Introduce formal division according to grade level.
- Use exact division initially.
- Introduce remainders only in appropriate advanced levels.
